# C14 post-gate compiled-component identity

This records-only supplement distinguishes the immutable pre-build
[C14 proof](V5-02-R15-R18-C14-proof.md) from the artifacts regenerated by the
complete host gates. It changes no source, test, measurement or original proof
data. Full platform and integrated acceptance remain separate.

The pre-gate proof verified 9,041 bindings and the preserved-binary controls.
During the complete builds, 114 raw hashes changed: 56 generated source/variant
archives and one ordinary runtime test executable in each configuration. The
source reviewer and final auditor independently classified every changed byte.
The original current-binding mismatch lists remain preserved.

For all **112 archives**, file sizes, member identities, non-time header fields,
symbol tables, member bodies and padding are identical. Only the exact 12-byte
mtime fields in the ar member headers differ. The compact overlay records old
and current raw hashes, a common timestamp-masked archive hash, and every member
payload hash. This is qualified metadata identity, not raw archive equality.

For both ordinary runtime test executables, file size, Mach-O header/layout and
every section payload are identical: 14 sections in Debug and 15 in Release.
The only differences are the 16-byte `LC_UUID`, 85 `N_OSO` object timestamps in
each executable, and the correctly derived CodeDirectory SHA256 code-page hash
slots. Eighty-four object timestamps correspond exactly to archive member times;
one corresponds to the direct `commands.t.cpp.o` object, whose body is unchanged.
No other symbol/string-table or load-command bytes differ.

Both reviewers recomputed all 31,254 Debug and 11,390 Release code-page hashes.
Changed pages intersect only the known UUID/timestamp locations. CodeDirectory
identity, policy, flags, layout, superblob indexes and padding are identical;
all four old/current signatures pass `codesign --verify --strict`. No unexplained
code, data, loadable payload or signature-policy change remains.

Current private measurement executables, instrumented sources, immutable input
snapshots, SDK headers and PCMs remain bit-identical. All 179 engine files and
190 product inputs remain unchanged; the C14 whole-source overlay still records
only the reviewed command-test edit. C13's actual normal/raised measurements and
descriptor fault results therefore retain their compiled-component scope under
this explicit post-build identity qualification. No new measurement execution
or blanket raw-hash match is claimed.

Compact records are `tests/native/r15-r18-c14-evidence/POST-GATE-ARCHIVES.json`,
`POST-GATE-MACHO.json` and `POST-GATE-IDENTITY.json`. They bind the complete raw
classifications under `tests/native/r15-r18-final-evidence/final-review-c14/`.
The independent bounded review and final integrated audit must explicitly retain
this qualification when granting carry and acceptance.
