# V5-02-X06-B2: original source-capture prerequisite

## Dispatch (2026-10-24)

### Objective

Implement the second X06 code row, "Original source-capture prerequisite", from the
[bounded delivery sequence](../profile-preparation-architecture.md#bounded-delivery-sequence-and-independent-gates),
realizing the X06A4-R1 design. A new `acceptance/source_capture` module provides a
bound factory that requires the original workspace-root receipt, the selected
declaration-file receipt and the registry receipt. It delegates existing load
internals; scoped capture bind forwarding is added only if search proves it
necessary.

### Acceptance criteria

1. The bound factory refuses construction without the original workspace root,
   selected declaration-file and registry receipts.
2. Known-load metadata admission of both the workspace root and the selected
   declaration file occurs before external registration. No source content is read
   during admission.
3. A module and the declaration that are hard links to one file in disjoint
   directories are refused before any external chunk executes.
4. A declaration replaced between registration and its first content read is refused.
5. Original-file `same_selection` plus actual-leaf verification is used with no
   receipt replacement.
6. Discovery, seal, move, precommit and poison state is retained across real profile
   admission.
7. A positive case with a distinct-file registry colocation succeeds.
8. A missing declaration returns the existing load-family diagnostic, and the test
   asserts that diagnostic and not only the timing (advisory X06A4C01-N1).
9. Existing metadata charges and terminal failure behavior are unchanged, and the
   existing profile transaction refusal is kept.
10. Regression tests that reproduce a defect are shown failing before the fix, with
    the evidence retained.
