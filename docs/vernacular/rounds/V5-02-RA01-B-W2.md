[authoring contract](../authoring-contract.md) (RA-2 to RA-7, Messages, acceptance checklist) and the

stand: the production binary has no authoring path (the eleven-row catalog and the authoring entry stay behind the `PLANAR_AUTHORING_BUNDLE`
