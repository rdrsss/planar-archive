## Exact C1 handoff

Fresh `/root/r14c1_search` recommends methods on existing format_file and inert
owned DTOs in its interface. Use read_head(), read_revision(id), read_event(seq),
read_request(key), read_events_after(cursor, limit). Single event/revision/request
lookups return expected<optional<DTO>, format_error>: a valid absent key is a
successful miss; malformed key, storage or decoding failure invalidates the
owner exactly like read_record. Existing read_record not_found semantics remain
unchanged. No new error enum entries or CLI error policy needed here.

DTOs own all strings: head/last_sequence; revision ID/parent/five refs/actor/time;
event seq/type/version/revision/request/actor/time plus exact saved payload; request
key/body reference/exact encoded record_v1 bytes/event/revision/outcome/exact saved
result. Keep B1 shared enum/reference types fully qualified or otherwise explicit
in exported declarations so both generated namespace variants remain valid.

Event page returns bounded owned events plus optional next_after, reflecting this
snapshot only. Explicit low-level limit 1..100; cursor 0 starts before event1,
otherwise <=signed64max. Ascending exclusive query, empty page successful, next
cursor only if more events remain. Validated gap-free seq and snapshot last_seq
can determine more without unbounded reads. State-at-event uses the event's pure
decoded after-state plus read_revision, no separate reconstructed-state cache or
policy API. Future CLI maps missing keys to its specified errors and enforces
transport output ceilings. This API deliberately exposes private request body
bytes only to native callers; public history must never emit host arguments.

Use one shared bounded row decoder per row kind. Bounds before copying: request
key128, actor256UTF8, time24, event/result1MiB; request record encoded64MiB per
existing record limit. Read exact stored body bytes after typed validation, not a
reconstructed request serialization. Preserve SQLite errors through storage(),
corrupt column shape/type separately, and invalidate all old/new methods on actual
failure. Cached metadata survives; moved-from owners refuse safely.

Coder owns format.cppm/.cpp, additive cases in history_verification.t.cpp reusing
its real B2 fixtures, src/engine/CMakeLists.txt only if necessary,
docs/architecture.md, docs/testing.md, and new tests/native/r14c1-evidence/.
No need for helper extraction, new SQL owner, schema/error vocabulary changes,
new writer, generator edits, Lua/CLI/vendor or prior evidence edits. Existing B2
cases must remain intact. Tests cover exact row/body/result bytes across later
heads, pages/cursors/limits, missing versus malformed keys, sticky failures across
all methods, owned result lifetime, raw access with unsupported interpretation,

read fault injection where existing fixture seams permit. All143priorfocused plus
