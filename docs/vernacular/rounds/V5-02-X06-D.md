### Objective

1. Whole-invocation composition. Give the initial profile factory one cumulative budget owner that is carried through
   capture, registration, declarations, shapes, conversion, preparation and the result, while preserving every stricter
   lower limit. Today the content, admission metadata, declaration-VM and retained trusted-VM metrics are distinct, each
   with its own storage. The architecture says later composition must inject a common budget owner from the initial
   factory into these stages rather than recapture, re-register or mint a fresh budget at preparation. Exhaustion, a failure
   caught by Lua, moves, and attempted reset or refund must all be tested. This is separate from merely retaining existing
   metrics. Search first inventories metric ownership and sizes so the composition is possible, and states which ceilings
   in X-LIMIT (Registration, Invocation, Declarations, Shape, Module capture) are composed and which stay lower
   inherited limits. No claim of RSS or capacity guarantees.
2. X06 integrated evidence. After the budget work is frozen: focused nonzero zero-skip gates first, then the complete agreed
   macOS Debug and RelWithDebInfo gates preserving every current test name and all prior evidence, plus lint, Doxygen and
   no-work builds. Measure N1 phase coverage if the integrated gate requires it, otherwise keep it recorded as a limit.

Out of scope: no `init` or envelope cutover and no public CLI change (X07); no Linux run (X08); no new public error code or
message (the closed message table of the [external-profile contract](../external-profile-contract.md) X-LIMIT stays
byte-identical, with exhaustion mapped to the existing `resource_limit`); no export or widening of the X06-C seam. The seam is
a non-exported partition of `planar.engine.ledger.acceptance` with a nested `seam_detail` namespace and a source-scan guard; it
stays as it is. The trusted in-tree code threat model applies, so adversarial C++ routes remain recorded limits.

### Acceptance criteria (the search invariant table must give each its own row, mutant and killing test)

Budget row:

B1. One owner: a single budget object created by the initial factory is the only source of cumulative charges for
    capture, registration, declarations, shapes, conversion, preparation and result. No stage creates a second budget, and
    preparation does not recapture or re-register.
B2. Lower limits preserved: every inherited stricter limit (declaration 64 MiB Lua and native, 1 million instructions per
    declaration chunk, per-module 1 MiB and 8 MiB total capture, shape and projection ceilings) still wins over the composed
    ceiling, and the composed ceilings (registration 10 million instructions, invocation 100 million instructions,
    4 million converted nodes, 512 MiB charged native conversion allocation, 512 MiB live Lua including retained
    registration) are enforced cumulatively across stages, with checked addition before allocation.
B3. Exhaustion: reaching a composed ceiling in any stage, including between stages and in preparation after phase8 and
    the all-job phases, fails with the existing `resource_limit` code and messages, leaves the owner terminal, and cleans
    up nested roots.
B4. Caught failure: a resource or semantic failure caught by Lua keeps the first terminal failure; no fresh owner, fresh
    budget or unbound retry follows.
B5. Moves: moving the invocation, factory or prepared object transfers counters and the budget; the source refuses;
    wrapper destruction cannot erase counters while the prepared object survives; move assignment cleanup is safe.
B6. No reset and no refund: temporary or cached storage, the selected declaration-file handle and comparison or discovery
    staging do not refund cumulative charges; final native preparation does not reset instruction, node or allocation
    counters; repeated operations share the budget.
B7. Boundary: exact-ceiling success and one-over failure for each composed counter that can be reached with small injected
    ceilings; any counter that cannot be observed without a new public field or fault hook is reported as a limit instead of
    getting a hollow test.
B8. Public surface unchanged: no new public permission, flag, error code or message; no new construction path for the
    prepared type; the seam source-scan guard still passes.

Integrated gate row:

G1. Focused nonzero, zero-skip runs of every X06 label and the new budget tests before the full runs.
G2. Full macOS Debug ctest, `--no-tests=error`, zero failures, zero skips, no timeouts, all 1041 current names preserved
    plus the new ones listed and counted.
G3. Full macOS RelWithDebInfo ctest with the same conditions, on the same frozen candidate, with its own inventory.
G4. Lint (`python3 scripts/rewrite-check.py lint --build-dir build/rewrite-debug`), clang-format, Doxygen, and a no-change
    build that does no work.
G5. All prior evidence preserved; carried limits recorded with updated status (P01 masked, N1 phase coverage unmeasured
    unless measured here, #531 timing, Linux not run).
