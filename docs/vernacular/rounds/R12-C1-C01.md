# R12-C1-C01 — Reject external super-journal authority

Status: complete; independently approved.

Depends on R12-C1-F01 from the independent C1 review. Same shared branch/HEAD,
existing rewrite changes and restrictions as [R12-C](R12-C.md). No Planar tools,
operator data, commits, installation or publication. Preserve the frozen C1
candidate and reviewer reproduction.

SQLite rollback journals may contain a trailer naming a super-journal. The
current recovery boundary validates only the leading hot-journal header and
does not constrain that reference. Independent reproduction recovered the
ledger successfully while deleting an external super-journal sentinel.

This single-database foundation must refuse super-journal authority before any
SQLite writable recovery, including scratch recovery. Inspect the pinned SQLite
trailer recognition rules and implement a conservative bounded preflight.
Delegate actual journal recovery to SQLite; do not invent a replacement journal
engine. Demonstrate the external-file regression before the fix and unchanged
refusal afterward. Preserve successful ordinary and redundant hot-journal
recovery, backup/restore and all existing refusal behavior.

Fresh search is read-only. Coder owns only the narrow ledger recovery
implementation/tests, affected reference clarification and new correction
evidence. Coordinator owns round records. Run all focused ledger cases,
formatting/Doxygen and no-work build; freeze candidate/evidence for fresh
independent high review. C2 remains pending.
