## Search handoff and API decisions

Fresh `/root/r13b2_search` completed read-only. Reuse
`planar.engine.value::valid_path` (`value.cpp:4–24`) for portable syntax;
add only cross-entry alias/duplicate/prefix checks. The codec validates local
records, while ledger `intern/read_record` validates stored references and edges.
No lower layer imports the new tree module. Select one logical capture root
outside this API; accept bounded path/payload views and normalized numeric modes,
and return owned sorted file entries for complete reconstruction.

Use explicit source/provenance profiles rather than caller-expandable maxima.
Root is depth zero and counts as a directory; file path segments count toward
the depth-64 maximum. Source includes at most 8192 directories including root.
The contract does not specify that same directory ceiling for provenance; its
maximum is instead bounded by 4096 file paths of depth at most 64 and their
ancestors (at most `1 + 4096 * 63` directories). Both profiles represent only
file ancestors and root, so reconstruction refuses non-root empty directories.
Check expanded occurrence counts before allocation/traversal; a shared node may
appear at many paths and must contribute at every occurrence. Keep traversal
scratch bounded, without retaining a maximum-size decoded record at every level.
All root/reference kinds and digests must agree; only file/directory descendants
are tree content even though the generic record codec permits other kinds.

Add narrow `record_writer::abort() noexcept`: release transaction state and
permanently invalidate the writer; it is idempotent, performs no commit, and
makes no stronger rollback-error reporting claim than existing abandonment.
Tree insertion takes `record_writer&`, returns a root reference without committing,
and aborts the entire writer on every expected input/limit/storage failure,
including failure before this tree inserts anything. This preserves earlier
pending trees/values only on success. Exceptions must also leave no committable
partial tree through an appropriate abort guard. Preserve original typed storage
errors within the tree error boundary, without leaking payloads or host paths.

Own new tree module/tests, only the abort addition in format interface/
implementation plus its colocated tests, engine CMake wiring, architecture/testing
references and new B2 evidence. Prior schema/primitive/codec, B1 collision helpers,
CLI/Lua/vendor and all evidence stay protected. Add tree to focused regex:
`replacement.(ledger|canonical|hash|record|tree)`. Baseline is 79 tests before B2.
Run both vectors, active and helper lint, exact B1/C2 generation audits, protection
checks and a zero-work build. Use correction-local audit snapshots for deliberately
changed files; never rewrite old manifests to fit the new candidate.

Boundary tests cover exact and excessive byte/file/directory/depth/path counts,
source and provenance differences, expanded shared subtrees, invalid aliases and
kinds, normal composition, explicit abort, and a failure after prior pending
inserts proving nothing commits. Retain all-kind forced collisions in B1; tree
storage-failure propagation must be tested without adding a product hash switch.
