## Search accepted; API and precedence decision

Both public operations require raw effective-tree files:
`decode_interpretation_v2(encoded,versions_encoded,raw_files)` and
`encode_interpretation_v2(bundle,semantic,raw_files)`. Keep self-structure parsing
private. Existing decode_catalog needs actual shipped/external path sequences, so
standalone public selfdecode would expose partially verified correspondence with
no approved need. New result owns interpretation/versions values and exact
canonical encodings (and recomputed digest if useful); it is not an acceptance
certificate or proof of sameVM semantic execution. Use a new v2 result/error type,
not old v1-only documented recorded_interpretation or live validation/runtime
error alternatives. Pure enum categories malformed, unsupported_version,
resource_limit, invalid_tree, invalid_correspondence; redact raw input/host bytes.

Decoder deterministic precedence: reject either encoded input above16MiB; decode
interpretation then separateV using canonical limits; validate outer keys/kinds,
v1-derived structural B/S containers/sorted job correspondence, E outer fields,
exactV key/type set/digest spelling and embeddedV exactcanonical byte equality;
then supported envelope/V constants (well-formed future -> unsupported_version).
E.catalog may have generic kind/component-size prechecks here, but its complete
contextual owner validation follows rawtree verification. Verify_effective_stdlib
internally verifies actual rawtree and supplies owned verified files/digest;
resource failures remain resource_limit, invalid provenance/manifest/membership
becomes invalid_tree. Decode catalog using ordered shipped/external paths derived
from verified manifests. Malformed asserted E.catalog -> malformed; valid but
different canonicalcatalog -> invalid_correspondence. Vdigest and B/S/E catalog
classification, exact custom selection/definition/module correspondence mismatches
-> invalid_correspondence; syntax failures remain malformed. Pin combined-error
precedence with tests. No v1 source or behavior change.

Encoder derives E/catalog/selected list and exactV natively from B/S structure
and internally verified rawtree; no caller V/E/digest input. Canonical roundtrip
severs aliases and final output passes identical structural/binding checks.
Private verified context reuse may avoid duplicate tree work, never a public
caller-supplied aggregate bypass. Caller B/S structural correspondence does not
prove live sameVM selection; later preparedacceptance owns that authority.
