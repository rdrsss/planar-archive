Implement all four normative record_v1 encodings and strict bounded decoding.

those IDs. Use pinned XXH3 with canonical sixteen-byte output, not render-domain
hashes or a handwritten hash. Keep the codec a leaf with no database/filesystem
or runtime access. Contextual graph/acceptance policy remains B/R14.

Add canonical_v1 decoding that reconstructs existing immutable values, including
empty map/list distinction, arbitrary string bytes, UTF-8 non-NUL sorted unique
map keys, signed-32 integers and clamped depth/node/byte bounds. Reject malformed
tags, lengths, ordering, duplicate keys and trailing bytes before unsafe
allocation. Encoding output and render identities must not change.

Use independent literal/standard-library binary fixtures rather than encoder
round trips alone. Cover exact modes/bytes, child-ID storage versus portable
digest, integer extremes, truncations, unknown versions/tags, oversized lengths,
invalid names/order/aliases and resource ceilings. Run nonzero focused
canonical/hash/record tests, formatting/Doxygen and no-work checks. Preserve
exact candidate snapshots/diffs and raw evidence for fresh independent review.
Full debug/release gates follow the integrated R13 milestone.
