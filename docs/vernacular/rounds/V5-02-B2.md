## Integration observations

Coder reported a publication gap before Lua observes the service result: native
export can succeed and subsequent allocation of returned facts can fail. The
service adapter must record successful publication before that allocation and
combine its retained flag with the VM's publication signal at the preallocated
response fallback boundary. A distinct deterministic test is required alongside
the existing response encoding/allocation failure cases. This preserves existing
export uncertainty semantics and introduces no new product policy.

Existing render CLI verification exposed a B1 integration defect: route/root
mapping mismatch was converted to internal4 in generic runtime validation,
preventing the historical reference/root refusal (exit3). Coordinator extends
coder ownership to runtime.cpp for the minimal correction: retain explicit
root.id type and route structural/path checks, enforce mapping equality in the
concrete native capture service before further captures, and retain the existing
typed diagnostic. Preserve the failing result as red evidence and include this
file in candidate/variant audits. No runtime API or exact contract body change.
