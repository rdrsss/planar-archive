# R14-B1 — Typed event and load-result codecs

Status: complete; independently approved with no findings.

Same shared branch/HEAD, approved v1 contract and restrictions as [R14-B](R14-B.md).
Fresh search defines exact DTO/API and existing Glaze value adapter usage before
coder dispatch. Coordinator owns round records. No Planar tools, operator data,

Add a storage-independent native codec for exact v1 event payloads and saved load
results. Glaze through the existing JSON adapter owns grammar, parsing, escaping
and serialization. Require fixed key sets/types, canonical decimal-string positive
signed-64 IDs and the `none` token only for optional IDs, exact reasons/outcomes,
ledger identity/request-ID grammar, and one MiB byte ceiling with no terminal LF.
Reject duplicate keys, malformed/noncanonical JSON and unsupported payload versions
with typed failures. Encode from typed DTOs; decode canonical bytes by parsing,
validating and comparing library re-encoding, never a hand JSON implementation.

Events are initialization (`none` to `none`, empty references), accepted revision
(optional before to newer nonempty after, five positive record references), and
no-op (same nonempty before/after, same five reference keys). Load results carry
exact version/kind/ledger/request_id/outcome/revision/parent/event fields. Parent
is the returned revision's stored parent, including no-op, and is absent or older
than that revision. Row/actor/timestamp/body/reference agreement is B2's cross-row
job. No clock, database, CLI, filesystem, Lua or public writer is added here.

Preserve current format implementation and its initialized/record-only refusal.
Compare new init encoding to current exact initialization payload. Pin independent
expected bytes for init/initial acceptance/change/no-op/revert, decimal max IDs,
no-op existing-parent behavior, missing/extra/wrong fields, wrong optional tokens,
unknown reason/outcome/version, duplicate keys, escape/trailing/ordering whitespace
and one-MiB refusal. Test meaningful typed round trips and no content/path leaks.

Provisional ownership is new `src/engine/ledger/history_codec.cppm/.cpp/.t.cpp`,
engine CMake, architecture/testing references, new B1 evidence. Confirm after
search. Protect format/schema/SQLite/history algorithms/interpretation/Lua/CLI/
vendor/prior evidence. Pure test link excludes SQLite/format/runtime/Lua. Run all
122 prior focused cases plus codec cases, CLI, vectors, lint, exact generation/
protection and no-work checks; freeze candidate for fresh independent review.
