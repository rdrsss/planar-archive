### Authority analysis (criterion 9, restated for this round)

1. Language visibility (now the structural layer). A module partition can only be imported by units of the same named module, so
   no code outside `planar.engine.ledger.acceptance` can name the seam, not even by importing the module file. The seam partition is
   not exported (not `export import`ed by the primary interface), so a plain importer of `planar.engine.ledger.acceptance` also cannot
   name it. The old module name `planar.engine.ledger.acceptance_seam` stops existing. This replaces both the passkey (forgeable per
   C02-R1) and the unreachable-by-convention link-graph reasoning (C01-R2).
2. The two adapters (embedded adapter in `acceptance`, `prepared_profile` adapter in the profile partition) are the only callers
   inside the module. Anything added to those units is trusted; the seam still does not recheck that values come from a real prepared
   object (storage verification remains the dynamic defence, and the opaque `prepared_profile` type and the I9 guard stay the
   authority for profile completion).
3. Source-scan test (kept, second check), updated to the new layout. Its blind spots remain: sources outside `src/`, generated
   sources, and a new unit added to the module itself (a module implementation unit of `planar.engine.ledger.acceptance` can name the
   seam by language rule; the scan is what limits which files may be such units).

Layer 1 does not rely on a convention and does not use friends, grant classes or any test hook. Known limits to state in the
record, not to hide: the profile-adapter partition makes `planar.engine.ledger.acceptance` import `planar.engine.runtime`, which
the C01 record had avoided; search must prove there is still no module or target cycle (runtime imports only
`planar.engine.ledger.completion`) and must decide how the generated atomic and metadata variants of `acceptance` (built by
`tests/native/r14c3b2-support/generate.py` and `v5-02-x03-b2-b-c01-support/generate.py`) are produced without the profile partition
or the runtime dependency. If that cannot be done without a product choice, report it instead of choosing silently.
