# C08 native saved-response correction

Implemented the approved C08 package. No self-approval or integrated acceptance is claimed.

`execution.cpp::check_request` now reconstructs the complete activation, claim/takeover, refresh, checkpoint and release saved responses through the existing typed encoders and compares exact canonical bytes. Common identity comes from verified metadata/request/event rows. Activation roles use the original activated-job transitions and generation ordinals; other-job retirement transitions are excluded. Claim/refresh dispatch hashes and byte length come from the retained dispatch and decoded packet file payload, preserving the existing packet/manifest validation. Run identity/token/ordinal and takeover previous-run use original immutable rows. Refresh drift is derived from its validated original transition grammar, and its response checkpoint is the row created by that event, not an older checkpoint carried in the dispatch. Release uses original event type and the target-first transition. No current-head answer or saved response field supplies expected values. Load/check/check-recover/verdict verification paths remain unchanged.

Only execution.cpp changes product behavior. Catalog and loader changes are test-only: a grammar-valid wrong shipped handler across all five historical epochs, and a declaration constructed before recoverable Lua growth so the later constructor cannot mask the execute-stage latch. Loader/catalog implementations, Lua, limits, interfaces and storage schema are unchanged.
