Map and implement a narrow typed record reader/writer over the approved SQLite
foundation. Share the pure record codec as a leaf; avoid ledger/tree dependency
cycles, raw handles and generic SQL exposure. Preserve the exact schema and
nonmutating foreign/future/corrupt refusal. Record-only initialized ledgers may

R14 composition, without committing partial trees. Include streaming full-record
validation that does not require materializing unbounded total history in memory.

Acceptance includes file/mode/binary/CRLF/empty trees, directory sorting and
aliases, rename/delete/mtime-independent content, reuse, complete old-tree
reconstruction, malformed references/cycles/encoded edges, and forced
leaf/internal/value/request collision refusal with rollback. Preserve failing
collision regression evidence before the protected exact-comparison behavior.
Narrow subrounds further if storage API and tree implementation exceed a
reviewable scope. Ownership and commands will follow fresh search.

## Search and implementation boundary

Fresh `/root/r13b_search` completed read-only. Split B into B1 typed storage and
full record validation, then B2 tree construction/reconstruction. The dependency
direction is the pure record codec, then ledger format/storage, then history
trees. Ledger may import the pure codec; it never imports the tree layer.

Extend the existing opaque format owner with bounded typed record reads.
Create an independently owned opaque writer from an explicit path, reusing
read-only format verification, safe writable transition, `BEGIN IMMEDIATE` and
in-transaction revalidation. Do not mutate an existing reader's shared snapshot
into a writer while aliases can still use it. The writer exposes typed intern/
read/commit operations, no SQL or handles; failure and abandonment roll back.
Its transaction can later support R14 composition without hidden tree commits.

B1 owns ledger format interface/implementation/tests, required engine CMake
dependencies, affected architecture/testing references and new B1 support/evidence.
Schema, SQLite primitive, approved codec, renderer, Lua and historical evidence
are protected. Use a mechanically generated test-only format variant for forced
digests, so validator and interning share the test hash without a product hash
override. Preserve normal product tests and exact generation proof.

B1 verifies all stored records/edges/hashes in streaming bounded passes and
refuses ambiguous buckets. Revisions/requests remain unsupported and event/current
state remains initialization-only. Backup/recovery inherit the same validated
record-only support; foreign/future/malformed and unvalidated-history refusal
remain unchanged. B2 follows only after independent B1 approval.
