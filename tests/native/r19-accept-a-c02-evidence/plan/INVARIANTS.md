## B2. Probe protocol, alternatives and credit rules (apply to every section B row)

Every row applies ITS OWN mutant text above, one raw log per mutant at `probes/raw/<id>.log` (alternatives: `probes/raw/<id>-<a|b|c>.log`), each log holding the applied diff, `diff_sha256`, source sha256 before and after, the restore check, the runner command (`perl -e 'alarm N; exec @ARGV' python3 -B -m unittest <module>.<Class>.<test>` from the scratch support directory, `PLANAR_CANDIDATE` set, `PYTHONDONTWRITEBYTECODE=1`), the `FAILED (failures=N)` line and the failing-test list. A kill is credited only when the failing list names the row's test (for rows naming two tests, both).
