# R19-ACCEPT-A invariant table (revision 3)

Unit ids are Python unittest ids (`python3 -m unittest <module>.<Class>.<test>` from tests/native/r19-accept-support). Every row is new behaviour (expectRed true): wave-1 tests run against stubs that return wrong values. Live classes need PLANAR_CANDIDATE (the D28 scratch-built `planar_authoring_stack`) and FAIL, never skip, without it. The heavy CMake rerun cannot be mutation-probed (hours); its logic is the F-rows driver and the I-rows lib, probed on the mini fixture; F11, F13, F14-F22 drive the cmake-rerun configuration with the real check swapped for the mini sleep check or stubbed commands. No row needs a new public product field or fault hook (faults are SIGKILL and process-level; `tamper` keys are driver config only, D32). Only the mutation prober applies mutants, in a scratch copy outside the checkout, under the D29 protocol (unmutated baseline pass in the same scratch copy with git objects and the candidate; each kill names the row's test with an AssertionError).
