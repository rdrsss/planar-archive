# R19-ACCEPT-A invariant table (revision 2)

Unit ids are Python unittest ids (`python3 -m unittest <module>.<Class>.<test>` from tests/native/r19-accept-support). Every row is new behaviour (expectRed true): wave-1 tests run against stubs that return wrong values. Live classes need PLANAR_CANDIDATE (source-built authoring-stack executable) and FAIL, never skip, without it. The heavy CMake rerun cannot be mutation-probed (hours); its logic is the F-rows driver and the I-rows lib, probed on the mini fixture, and F11/F13 drive the cmake-rerun configuration with the real check swapped for the mini sleep check. No row needs a new public product field or fault hook (faults are SIGKILL and process-level). Only the mutation prober applies mutants, in a scratch copy outside the checkout.
