# R19 CMake task invariant table

Read alongside DECISIONS.md and the bounded search map. This is a build-organization refactor;
no new runtime behavior or public test fault hook is required. Mutants below are proposed verification
sensitivities, not already executed faults. The coordinator/coder records actual baseline/candidate commands.

| ID | Acceptance criterion / invariant | Concrete breaking edit | Observable check that must fail |
| --- | --- | --- | --- |
| I1 | Every existing engine directory owns a CMakeLists, each non-root is reachable once through its immediate parent's explicit add_subdirectory; no nested project(). | Omit `add_subdirectory(closure_guard)` or leave capture without its CMakeLists. | Directory/reachability audit and actual configure/codemodel target set comparison. |
| I2 | All existing module/library/executable targets and their types remain; no duplicate or missing targets. | Drop `planar_capture_directory` or rename its target. | Exact baseline/candidate target-name/type set comparison and configure/build. |
| I3 | Product/test source and module-interface membership stays exact after only permitted source/generated-path rebases. | Omit `execution_review.cpp` or a ledger format test source during extraction. | Exact per-target source/FILE_SET comparison, generated payload hashes and full test inventory/build. |
| I4 | Resolved dependency edges stay equal; no extra product test-library edge. | Remove `planar_runtime` dependency `planar_closure_guard`, or add a test harness to a production target. | Exact baseline/candidate target dependency and resolved link edge comparison, normal all dependency closure. |
| I5 | Compile definitions/options/include paths and injected test ceilings remain equivalent; no public/path-independent definition is waived. | Drop `PLANAR_BUDGET_INSTRUCTION_MAX=29000000` from runtime tests or change a fixture macro. | Per-target compile configuration comparison using a small explicit generated-path translation only; full runtime tests. |
| I6 | Generated bridge/embedding/generator outputs preserve exact payloads and configure dependencies; no extra suffix or wrong source directory. | Leave `runtime/runtime.cpp` after moving into runtime, or lose an `@ONLY` rewrite. | Fresh configure, generated-byte comparison with precise path-only exceptions, exact-module tests and meaningful no-work repeat. |
| I7 | Every existing CTest name remains registered exactly once with its policy, arguments, fixture selection and timeout. | I9 | Supported configure/build paths remain deterministic; no-change build does no work and applicable format/Doxygen checks pass. | Replace file(CONFIGURE) with an always-touched output or introduce a live-Git input. | Actual repeated build output and existing full gate; fresh configuration checks directory-relative assumptions. |
| I10 | Ownership/refactor boundaries and historical evidence remain honest.
