## Part 2: Python suite reporting and the rerun index (new behaviour; explicit run by the GATE stage, D19, D38)

Interface: `python3 run_acceptance.py suites --support-dir DIR --module NAME [--module NAME ...] [--live-module NAME ...]
[--record PATH] --out FILE`. For each module it runs `sys.executable -B -m unittest -v NAME` (never a bare `python3`, D19) with `cwd=DIR`, parses the final
`Ran N tests` / `FAILED (...)` / `OK (skipped=S)` line, writes FILE (and prints) one line per module
`NAME ran=N failures=F errors=E skipped=S exit=X` and a last line `total ran=.. failures=.. errors=.. skipped=..`. Exit 0
only when every module has `ran > 0`, `failures == errors == skipped == 0` and child exit 0. Live modules require
`--record` and `lib.require_recorded_candidate` before any child starts. The stub (PKG-B) prints
`run_acceptance: suites not implemented` on stderr, returns 2 and writes nothing.
