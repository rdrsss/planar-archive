# C2-B2 ownership, protected frames and source accounting

The bridge admits a typed, descriptor-matched record and recursively validates ordinary transport. Native callers guarantee the selected-role/verified-history authenticity precondition. This slice does not construct those authenticated reads, supply services, or open public commands.

Projection identity resolves before F. A private ordinal parameter to the existing resolver preserves its standalone index-zero behavior while allowing an invocation's first resource failure to retain the original one-based projection index. The resolver's original identity/hash/copy accounting is unchanged. Existing first terminal errors win before any new guards or adaptation.

`sizeof(projection_scan)` charges the fixed 64-entry `projection_section_view` array, count/text counters and refusal discriminator before execution. It is logical fixed workspace capacity, not a stack-frame/RSS measurement. The scan itself has only trivial locals and destructors. It runs in a Lua protected frame with checked stack capacity; raw backing, tag, field and iteration operations never invoke user code. Its exact schema bounds traversal to root, list and at most 64 fixed records. No result AST, native string copy or codec scratch allocation precedes scan admission. The actual root stays in stack slot1 across the scanner call, the outside-Lua B1 exact count and its charge callback, and later conversion. View bytes are not retained beyond this synchronous operation.

The unchanged B1 writer charges its source-derived fixed workspace plus 6,325,248-byte scratch request before allocation. Its typed callback resource diagnostic is preserved; encoded overflow maps to the existing closed external resource diagnostic. Existing `convert` then charges node/control-block capacity, field/list growth and copied strings through its established cumulative accounting. No second encoded output buffer is created. Identity, diagnostics and owned response copies retain the pre-existing native boundary accounting/exception adapters.

`execute_shape` supplies alias-preserving native input push, private proxy freezing and the retained callback. Its existing lazy baseline and cleanup are reused, without new production registry roots or references. Cleanup removes invocation tag/backing membership on every bridge exit, while all inherited original references/table identities remain exact. The inherited lazy bookkeeping has two private baseline-map keys: a controlled failure while constructing the second may leave the first map until terminal owner destruction. Private probes explicitly report this one-map partial state; they do not claim complete registry-key equality for those two lazy bookkeeping keys. The original registry membership excluding those two known bookkeeping keys, and all tag/backing/sealed entries, are compared by actual key/value identity pairs, not merely by counts/checksums. Repeated successful cleanup also compares exact identities.

The private production copy forces GC after scan while the root remains live, observes unchanged AST node count until exact-count success, observes the B1 reservation before copy, samples every actual one-shot native allocation request through identity/call/scan/count/copy/return, and compares the first diagnostic across projection/shape/definition/render/select/validate retries and moves. Quota probes set controlled remaining accounting/heap/instruction states; they exercise actual production refusal paths and do not claim natural exhaustion. The partial-baseline probe injects an actual allocator refusal, including emergency retries, immediately before the second lazy map allocation. Unknown-metatable injection is a controlled adapter because external Lua cannot install arbitrary metatables. No probe is evidence of final native read-service authenticity.
