# V5-02-R15-A2 evidence folder

This folder holds the evidence of the documentation round V5-02-R15-A2 (execution contract, part 2) and of its corrective rounds V5-02-R15-A2-C01 and V5-02-R15-A2-C02. The round record is [V5-02-R15-A2](../../../docs/vernacular/rounds/V5-02-R15-A2.md); the corrective records are [V5-02-R15-A2-C01](../../../docs/vernacular/rounds/V5-02-R15-A2-C01.md) and [V5-02-R15-A2-C02](../../../docs/vernacular/rounds/V5-02-R15-A2-C02.md), whose "Results" sections list the red-run figures, the probe results and the finisher outputs. The probes and the finisher outputs are not in this folder; they are in `tests/native/v5-02-r15-a2-c01-evidence/` and `tests/native/v5-02-r15-a2-c02-evidence/` (see the layout table). The "Verification commands" section of the R15-A2 record gives the exact commands, and the "Invariant table" sections list the checks that the logs refer to.

The folder is gitignored (`/tests/native/*-evidence/` in `.gitignore`). The coordinator commits selected files with `git add -f`, and only manifests and small reports are committed. Raw logs stay local.

## Rules

- No log is deleted. A re-run keeps the earlier log as `<id>.attempt-<n>.log` (or `.attempt-<n>.txt` for the red runs) before the new log is written.
- Nothing under `tests/native` is run in place. The checker and the link check are copied into a scratch directory outside the checkout and run there against the frozen inputs in this folder. `red/stub-tree/make-stub-tree.py` is copied the same way.
- Hashes come only from the workflow identity tool. Its output is pasted or copied verbatim, never computed by hand. The identity tool covers tracked changes and untracked files that are not ignored, so it gives no per-file hash for the gitignored folders.
- Scoped exception (C01-D14): because `identity.py` cannot cover ignored paths, the per-file `shasum -a 256` output and the `git ls-tree` blob IDs, pasted verbatim from those tools, are allowed only for the gitignored `base/` snapshot (in `red/snapshot-identity.attempt-2.txt`, byte-equal to the unsuffixed `red/snapshot-identity.txt`). C02 adds a second scoped exception (C02-D10, C02-D26): the verbatim `shasum -a 256` output of the gitignored checker copies and fixtures run by the red and probe packages, recorded in their own evidence files. Hand-computed hashes remain forbidden everywhere in this folder and in the round records. The round record states this limit.
- The checker reads `base/` and compares it with `git show <base-commit>:docs/vernacular/<file>` for the recorded base commit. It never reads `HEAD`, because `HEAD` moves when the round is committed.
- The mutation probes run in scratch copies. Nothing in the checkout is mutated.
- Paths in this folder use the placeholders `<repo>`, `<scratch>` and `<home>`, not machine-local paths.
