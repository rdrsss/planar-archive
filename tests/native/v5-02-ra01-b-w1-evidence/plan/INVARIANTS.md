## Validator statement contract (I1 must write these statements, mutants name them)

In `seal_catalog` each check is its own statement (no `||` chain) and there is NO row-count comparison anywhere (D5):
`S0` row lookup `find_bundle_row(name, c.authoring)` skips rows with `authoring_only && !authoring`; `S1` `if (!row) command_refuse();`;
`S2` `if (!names.insert(name).second) command_refuse();`; `S3` family equals name; `S4` handler id equals `row->handler`; `S5` response kind equals `row->kind`;
`S6a` capabilities is a list of one string; `S6b` the string equals `row->capability`; `S7a` options is a list; `S7b` `options->items.size() != signature.size()`;
`S8` `if (it == signature.end()) command_refuse();`; `S8b` duplicate option name; `S9` option type equals `it->type`; `S10a` required is a boolean; `S10b` required equals `it->required`;
`S11` presence loop `for (const auto& expected : bundle_rows(c.authoring)) if (!names.contains(...)) command_refuse();` where `bundle_rows(false)` is the five shipped rows and
`bundle_rows(true)` all eleven. `seal_environment` sizes its root array by `command_registration_cap` (64) and has no count refusal.
Selection statements (D2, D3): `K0` `constexpr bool authoring_bundle_selected` is `true` under `#ifdef PLANAR_AUTHORING_BUNDLE` and `false` otherwise; `K1` in `create_impl`
`c.authoring = authoring_bundle_selected && !profile;`; `K2` at the `registration` table creation, under the same `#ifdef`, `if (!commands(l).profile)` sets `registration.authoring = true`.
Why each check is unmasked: with no count check, a catalog with a given single defect is caught by exactly one statement (missing row: only S11; extra row: only S1; duplicate
with all eleven present: only S2; mispair: only its own equality; missing option: only S7b; renamed option: only S8; type: S9; required: S10b; ungated rows in a default VM: only S1/S0).
A permissive mutant therefore yields a SEALED VM and the test fails with "expected refusal, got a sealed VM" naming the row (`CAPTURE(row)`), and no mutant indexes an array out of range.
