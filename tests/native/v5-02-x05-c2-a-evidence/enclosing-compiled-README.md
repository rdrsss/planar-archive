# Additional enclosing compiled identity proof

The frozen owned driver inherited the previous round's snapshot scope:
`build/rewrite-debug/src` object/PCM/archive membership and bytes (748 files).
Those individual before/after checks are accurate for that narrower scope.
They do not cover the 140 compiled root/vendor files.

Before any final private probe was launched, an evidence-local wrapper was
written and SHA256-frozen in enclosing-wrapper-sha256.json. Its `before` command
requires that final-probes does not exist, and captures all 888 Debug compiled
root/src/vendor object/PCM/archive files. After the existing final gate's isolated
private compile/link/run commands complete, `after` verifies identical complete
membership+bytes and binds the seven private commands by SHA256 and zero statuses.
The wrapper's exact argv, timestamp and hash are in the start/final JSON records.

This independently enclosing proof strengthens the compiled identity audit without
modifying frozen candidate support/product/prose or rerunning unaffected focused
cases. The ordinary finalization snapshot of all compiled files is separate.
Source/PCM/dep outputs remain private as recorded in driver command arrays.
