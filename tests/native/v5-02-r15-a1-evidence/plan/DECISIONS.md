## M. Role state machine rows (D72, D90, D91, D94; authoritative; revision 4)

State cells are the six state names; `running+drift` means `running` with drifted=1; `running` alone means drifted=0. A comma list in the before cell is shorthand for one row per listed state with the same cause, after, reason and events. Every row writes one `transitions` row per role in the carrying event. Structural, activation and removal rows write a transitions row even when the state name is unchanged, because the generation changes. Rows whose before or after state is `done` or `stale` are normative now but reachable only once R17 facts (completions) exist; R15 itself never produces a completion.

Event column (D90). A row lists EVERY event that can carry it.
