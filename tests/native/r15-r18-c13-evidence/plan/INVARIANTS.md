# C13 invariants and sensitivity plan

All mutations run in private scratch copies, never in candidate/source build directories. A diagnostic red run is not a completed correctness gate.

| ID | Acceptance invariant | Exact breaking fault / control | Required observation |
| --- | --- | --- | --- |
| I01 | Exact Linux provenance precedes the repair. | Falsely classify an unobserved fd3 as probe-owned/CTest-owned. | Record exact pinned toolchain/source identity and actual native-test-process fd3 target/flags, matching external parent target and separation from owned handles. Missing capture or an unmatched process is incomplete, not success. |
| I02 | Linux engine honors owned-descriptor CLOEXEC. | Private runner.cpp change pipe2(fds,O_CLOEXEC) to pipe2(fds,0). | Healthy final leak test passes; same test must fail under mutant with actual leaked pipe fd, after any fixture isolation. |
| I03 | devnull CLOEXEC remains observable. | Private runner.cpp change open(/dev/null,O_RDONLY|O_CLOEXEC) to O_RDONLY. | Healthy final leak test passes; mutant must expose the owned devnull descriptor and fail. |
| I04 | macOS default CLOEXEC still has test sensitivity. | Private configure_attributes omits POSIX_SPAWN_CLOEXEC_DEFAULT. | Existing normally inheritable subject descriptor, created AFTER ambient isolation, is reported and fails the negative test. Existing O_CLOEXEC subject alone is insufficient for this row. |
| I05 | Leak probe cannot be replaced by always-empty output. | Private probe suppresses all descriptor reports. | Exact fd9 positive control fails; retain its original expected `9\n`. |
| I06 | Ambient fixture cleanup is real and preserves parent state. | Private fixture omits original-flag restoration, or marks descriptors only after creating test subjects. | Meaningful held inheritable marker (not hardcoded fd3; e.g. dynamically duplicated fd>=24) has original flags and validity restored after fixture. I04 additionally detects late capture masking the macOS inheritable subject. |
| I07 | C13 fixture repair normalizes pre-existing harness descriptors rather than ignoring observed leaks. | Linux test process deliberately launched with inheritable marker fd3 and another available descriptor (e.g.23), versus clean launch. | Before repair diagnostic shows actual markers through original probe; after fixture repair exact empty/fd9 outputs hold, while I02/I03 still fail. This is no blanket fd3 exemption. |
| I08 | Product source remains unchanged for the conditional fixture branch. | Any unreviewed change in runner.cpp/cppm, other product inputs or limits. | Per-file hash compare of all190 product inputs; only approved test/record scope may differ. If product fault is proven, remap/review its separate scope. |
| I09 | Actual normal D15 tables correspond to final engine source. | Reuse C11 source272 claim after runner.t.cpp changes, or report earlier runs as later-source measurements. | Actual post-final-edit Debug+Release normal runs, exact inventories/nonzero assertions, current before/after source hashes and regenerated compact bindings. No unsupported raised/budget carry. |
| I10 | Complete platform closure executes final bytes. | Count Dockerexit0 despite CTest8, omit failed names, skip tests, or let docs/source change during context freeze. | Every exported configure/build/CTest/inventory/no-work exit checked; actual count/inventory and zero skips; host-before/after/container context equality; final Linux source and final runner test hash binding. |
