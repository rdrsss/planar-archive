# R20-CARRY-A evidence folder

Index of `tests/native/r20-carry-a-evidence/` (the R20-CARRY-A gate run1 folder). The folder is gitignored. Committed files are added with `git add -f` by explicit path under the C01 commit set (D27): `REPORT.md`, `README.md`, `plan/DECISIONS.md`, `plan/INVARIANTS.md`, `red/RED.md` and `probes/PROBES.md`, together with the C01 records in `tests/native/r20-carry-a-c01-evidence/`. Everything else stays local. Read `REPORT.md` first, then the C01 index below. Final-candidate status and the invariant table are in `docs/vernacular/rounds/R20-CARRY-A.md`.

- `REPORT.md`: the gate report (run1, R20-CARRY-A candidate) and evidence report (red-first runs, green runs, identity outputs, CMake diff classes, byte identity, timings and margins, nearest-limit table, mutant per new test, limits, commit list, redaction). Unreviewed until the coordinator's review passes. Its loaded-margin criterion was NOT MET for the run1 candidate (limit 120 s). The C01 candidate's loaded result is not recorded here: see `tests/native/r20-carry-a-c01-evidence/REPORT.md`.
- `README.md`: this index.
- `CODER-REPORT.md`: the coder's own report (wave 1 to 5 state; its statements that the Release and Linux gates are outstanding are superseded by `REPORT.md` run1). Not a gate report. Local only, not committed: its redaction check fails on a local path (`redact-local-paths.py check` exits 1), so it stays out of the commit set.
- `inventory.txt`: the 1,872 registered test names.
- `plan/`: `DECISIONS.md` and `INVARIANTS.md` (authoritative plan tables, revision 4); `superseded-1..3/` hold earlier revisions. Prove the intended behaviour and the mutant for every test.
- `red/`: test-wave red check. `RED.md` summary, `raw/<case>.log` per-case failing output on the pre-fix tree, `snapshot-2/` (candidate.diff, SHA256SUMS, untracked list) identifies the red tree; `snapshot/` is incomplete and superseded. Proves each expect-red test fails behaviourally before the fix.
- `raw/redfirst/`: PKG-T pre-fix evidence: start identity and state, baseline no-work build proof, ctest-N of the 18 new names, the all-18 red run, call-site and CMake-root inventories, disk.
- `raw/verify/`: PKG-V post-fix configure, build and no-work logs, the `replacement.r20` run (18 passed) and the two slow tests.
- `raw/real-tree-zero-work/`: I17/I25 scratch-tree runs: configures, builds 1 to 5, mtime snapshots and diffs, baseline counterparts, runtime module sha before/after, `NOTE.txt` with the findings and the dyndep deviation.
- `raw/idle/`, `raw/load/`: idle timings (3 runs per test) and the K=160 load runs (C0 direct, C1 ctest, `load.sh`, transcript). Proves limit/idle and the LOAD-MARGIN-FAIL.
- `raw/nearest-limit/`: full Debug ctest log, `tests.json` (TIMEOUT values), `table.txt` (ratio table), exit and start markers.
- `raw/ctest-names-{before,after,diff}.txt`: registered-name baseline (1,854) and result (1,872).
- `raw/embed-bytes-{before,after,diff}.txt`: byte identity of every generated `*_source*.cppm` (diff empty).
- `raw/identity-*.txt`, `raw/git-diff-cmakelists.txt`: identity captures and the CMake diff classification (zero unclassified).
- `raw/timings.txt`: PKG-E timing summary and the D32 outcome.
- `raw/commit-list.txt`, `raw/redaction-check.txt`: SUPERSEDED. Written against the earlier coder report, so stale. They are kept as history and not deleted. The current versions are regenerated by the coordinator in `tests/native/r20-carry-a-c01-evidence/raw/` (`commit-list.txt`, `redaction-check.txt`; D29).
- `raw/run1/`: final gate logs (Debug, Release, Linux, support suites, redaction).
- `probes/`: mutation prober `PROBES.md`, `probe-driver.py`, raw logs; `probes/superseded-2/` holds the pre-repair run.

- `tests/native/r20-carry-a-c01-evidence/plan/` (`DECISIONS.md`, `INVARIANTS.md`), `red/RED.md` (red-first on the 120 tree) and `probes/PROBES.md` (committed); `raw/`, logs and snapshots stay local.
